# Contrato: logs

Nunca: `conteudo`, `texto`, nome, telefone, documento.

PODE: `id_trabalho`, `id_mensagem`, `id_reserva`, `id_hotel`,
`tipo`, código de erro, `janela_fechada`.

Eventos:

- `resposta_recepcao_enfileirada`
- `resposta_recepcao_enviada`
- `resposta_recepcao_envio_falhou`

A tela não escreve o corpo em `console`.
